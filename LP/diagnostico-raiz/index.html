Você já tentou mudar, mas sente que algo dentro de você continua puxando para o mesmo lugar?

Talvez você saiba exatamente o que deveria fazer. Talvez você já tenha pensado, analisado e prometido para si mesma que dessa vez seria diferente.

Você evita conversas importantes.
Você se cobra demais.
Culpa ao se priorizar.
Trava diante de decisões.

Isso não significa falta de força. Significa que existe uma raiz emocional ainda não compreendida.

Nem todo bloqueio começa no presente.

Muitos comportamentos atuais são respostas automáticas formadas a partir de experiências e significados antigos. O Diagnóstico é uma investigação guiada para compreender de onde vem o padrão.

"Aqui, o foco não é julgar o que você sente. É organizar, nomear e compreender o que seu sistema emocional está tentando mostrar."
